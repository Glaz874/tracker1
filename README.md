# Учёт командировочных расходов

Проект команды по дисциплине «Программная инженерия», осень 2026/2027.
Основа — индивидуальная работа по дисциплине «Проектирование ИС».

## Проблема и пользователи

Сотрудники сдают авансовые отчёты в бумажном виде, бухгалтерия вручную
сверяет чеки и рассчитывает суммы. Пользователи: сотрудники, бухгалтер,
руководитель отдела.

## Ключевые функции первого релиза

- подача заявки на командировку;
- загрузка чеков и формирование авансового отчёта;
- кабинет бухгалтера: проверка, утверждение/отклонение отчёта.
